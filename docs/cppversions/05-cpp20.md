# 05 — C++20: Concepts, Ranges, Coroutines, Modules

C++20 là bước nhảy lớn thứ hai (sau C++11). Mạnh về generic programming, async style, và modularize. Toolchain/Qt cần đủ mới.

```bash
c++ -std=c++20 -Wall -Wextra docs/cppversions/samples/cpp20/*.cpp
```

> Một số feature (Modules, một phần Ranges/Calendar) phụ thuộc mạnh compiler + standard library. Kiểm tra hỗ trợ trước khi dùng production.

---

## 1. Bốn trụ cột lớn

| Trụ cột | Ý nghĩa |
|---------|---------|
| **Concepts** | Ràng buộc template đọc được, lỗi compile rõ hơn |
| **Ranges** | Algorithms + views dạng pipeline |
| **Coroutines** | `co_await` / `co_yield` / `co_return` |
| **Modules** | Thay/giảm phụ thuộc header `#include` |

Ngoài ra: `constexpr` cực mạnh, `span`, `format`, calendar/timezone, `jthread`, `source_location`, `<=>` (spaceship), `std::atomic` wait/notify…

## 2. Concepts

### Vấn đề cũ

```cpp
template <typename T>
T add(T a, T b) { return a + b; } // lỗi khó đọc nếu T không có operator+
```

### C++20

```cpp
#include <concepts>

template <std::integral T>
T addIds(T a, T b) { return a + b; }

template <typename T>
concept PriceLike = std::floating_point<T> || std::integral<T>;

template <PriceLike T>
T fee(T notional) { return notional * T(0.001); }
```

Hoặc `requires`:

```cpp
template <typename R>
requires requires(R r) { r.begin(); r.end(); }
void sort_range(R& r);
```

Lợi ích học tập: biến template từ “ma thuật” thành API có contract.

Mẫu: `samples/cpp20/01_concepts.cpp`

## 3. Ranges & Views

```cpp
#include <ranges>
#include <vector>
#include <algorithm>

namespace rv = std::views;

std::vector<int> qty{1, 2, 3, 4, 5, 6};
auto even_sq = qty
    | rv::filter([](int x){ return x % 2 == 0; })
    | rv::transform([](int x){ return x * x; });

for (int v : even_sq) {
    // 4 16 36
}
```

Khác iterator cặp `begin/end` cổ điển: pipeline dễ đọc hơn, lazy evaluation với views.

Chú ý: một số view không own data — lifetime vẫn quan trọng.

Mẫu: `samples/cpp20/02_ranges.cpp`

## 4. Coroutines (ý tưởng)

Coroutines cho phép hàm tạm dừng / tiếp tục — nền cho generators, lazy sequences, async tasks.

```cpp
// minh họa ý tưởng — runtime coroutine type cần framework (hoặc tự viết promise)
Generator<int> counter(int n) {
    for (int i = 0; i < n; ++i)
        co_yield i;
}
```

Thực tế production thường dùng:

- thư viện (Folly, cppcoro, Boost.Asio + awaitable)
- hoặc Qt + co_await adapters (tuỳ hệ sinh thái)

Với trading-app v1: **không bắt buộc**. Market feed dùng `QTimer` đơn giản hơn.

Mẫu khái niệm: `samples/cpp20/03_coroutines_notes.md`

## 5. Modules (ý tưởng)

```cpp
// math.cppm / math.ixx (cú pháp phụ thuộc compiler)
export module math;
export int add(int a, int b) { return a + b; }

// main.cpp
import math;
int main() { return add(1, 2); }
```

Mục tiêu: compile nhanh hơn, encapsulation tốt hơn header. Hệ sinh thái build (CMake + compilers) đã khá hơn theo thời gian nhưng vẫn cần cấu hình cẩn thận.

Với dự án đang học Qt/SQL: **có thể trì hoãn Modules**.

## 6. `std::span` — view trên mảng liên tục

```cpp
#include <span>

void normalizePrices(std::span<double> prices) {
    for (double& p : prices) if (p < 0) p = 0;
}

double arr[3] = {1, -2, 3};
normalizePrices(arr);
std::vector<double> v{1, 2, 3};
normalizePrices(v);
```

Không own memory; giống `string_view` nhưng cho phần tử tùy ý.

## 7. `std::format` (C++20)

```cpp
#include <format>
#include <iostream>

std::string line = std::format("{} qty={} price={:.2f}", "AAPL", 10, 190.5);
std::cout << line << "\n";
```

Sạch hơn `stringstream` / printf lai. Một số compiler gắn `format` hơi trễ — kiểm tra phiên bản.

## 8. Three-way comparison `<=>`

```cpp
#include <compare>

struct Version {
    int major{}, minor{};
    auto operator<=>(const Version&) const = default;
};

Version a{1, 2}, b{1, 10};
if (a < b) { /* true */ }
```

Compiler sinh `< > <= >=` khi defaulted đúng cách.

## 9. `constexpr` “hầu như là runtime subset”

Nhiều thuật toán STL trở thành `constexpr`. Có thể tính nhiều thứ lúc compile (lookup table, parsing đơn giản…).

```cpp
constexpr double clamp_price(double p) {
    if (p < 0.01) return 0.01;
    if (p > 1e9) return 1e9;
    return p;
}
static_assert(clamp_price(-1) == 0.01);
```

## 10. Calendar / timezone (`chrono` mở rộng)

```cpp
#include <chrono>
using namespace std::chrono;

auto day = 2026y / August / 9d;
// timezone cần data tzdb — phụ thuộc nền tảng
```

Hữu ích cho timestamp giao dịch, nhưng SQLite thường lưu ISO text/`datetime('now')` cũng đủ v1.

## 11. `std::jthread` & `stop_token`

```cpp
#include <thread>

std::jthread worker([](std::stop_token st) {
    while (!st.stop_requested()) {
        // work
    }
}); // join tự động khi destroy + request stop
```

Sạch hơn `std::thread` cổ điển cho worker loop.

## 12. `source_location` cho log

```cpp
#include <source_location>
#include <iostream>

void logInfo(const std::string& msg,
             const std::source_location loc = std::source_location::current()) {
    std::cout << loc.file_name() << ":" << loc.line() << " " << msg << "\n";
}
```

Nâng `LoggerService` của repo lên chuyên nghiệp hơn.

## 13. Có nên dùng C++20 cho trading-app ngay?

| Điều kiện | Gợi ý |
|-----------|--------|
| Học concepts/ranges có chủ đích | ✅ bật C++20 dần |
| Qt version + CI compiler hỗ trợ tốt | ✅ |
| Muốn ổn định nhanh Phase 0–3 | Cứ **C++17**, cherry-pick tinh thần |
| Modules/coroutines bắt buộc? | ❌ không cho v1 |

Chiến lược thực dụng: **compile với C++20**, nhưng chỉ dùng subset ổn định (`span`, `format` nếu có, concepts nhẹ, `jthread`).
