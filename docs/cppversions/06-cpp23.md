# 06 — C++23: Tiện dụng và hoàn thiện C++20

C++23 thiên về “làm DX tốt hơn” hơn là thay đổi mô hình tư duy. Nhiều thứ trước phải tự viết / dùng thư viện nay có trong chuẩn.

```bash
c++ -std=c++23 -Wall -Wextra docs/cppversions/samples/cpp23/*.cpp
# nếu compiler chưa có c++23: thử -std=c++2b
```

---

## 1. Headline features đáng quan tâm

| Feature | Dùng để làm gì |
|---------|----------------|
| `std::expected` | Success/error có giá trị — thay `optional`+error code tách / exceptions cho business errors |
| `std::print` / `println` | In ra stdout/stderr đơn giản, dựa trên format |
| `std::mdspan` | View đa chiều lên buffer liên tục |
| `std::flat_map` / `flat_set` | Map/set dựa trên vector — cache-friendly, nhỏ |
| Ranges additions | `zip`, `enumerate`, `join_with`, `chunk`… |
| `std::move_only_function` | `function` cho move-only callables |
| `std::generator` (coroutine) | Generator chuẩn |
| `std::stacktrace` | Stack trace khi debug/crash (tuỳ implement) |
| Multidimensional subscript `v[i, j]` | Cho mdspan/matrix-like |
| `if consteval` | Phân nhánh compile-time vs runtime rõ hơn |
| `std::byteswap`, `to_underlying` | Tiện ích nhỏ rất đáng dùng |
| Modularized standard library | `import std;` (support dần) |

## 2. `std::expected` — cực hợp trading use-cases

```cpp
#include <expected>
#include <string>

enum class OrderError { InsufficientFunds, InvalidQty, UnknownSymbol };

std::expected<int, OrderError> placeBuy(int qty, double cash, double price) {
    if (qty <= 0) return std::unexpected{OrderError::InvalidQty};
    if (cash < qty * price) return std::unexpected{OrderError::InsufficientFunds};
    return 42; // order id
}

auto r = placeBuy(10, 1000, 190);
if (r) {
    useOrderId(*r);
} else {
    handle(r.error());
}
```

So với `Result<T>` tự viết trong docs trading-app: `expected` là phiên bản chuẩn hóa.

Mẫu: `samples/cpp23/01_expected.cpp`

## 3. `std::print`

```cpp
#include <print>

std::print("Filled {} x {} @ {:.2f}\n", "AAPL", 10, 190.5);
std::println(stderr, "reject: {}", "insufficient funds");
```

Gọn hơn `iostream` cho log/line-oriented output. Chưa thay thế hoàn toàn logging framework.

---

## 4. `std::flat_map`

```cpp
#include <flat_map>
#include <string>

std::flat_map<std::string, double> quotes{
    {"AAPL", 190.0},
    {"MSFT", 420.0},
};
quotes["TSLA"] = 250.0;
```

Phù hợp bảng giá nhỏ / config lookup — thường nhanh hơn node-based `map` với N nhỏ-trung bình nhờ locality.

## 5. Ranges: `zip` / `enumerate` (tinh thần)

```cpp
#include <ranges>
#include <vector>
#include <print>

std::vector<std::string> symbols{"AAPL", "MSFT"};
std::vector<double> prices{190.0, 420.0};

for (auto [i, sym, px] : std::views::zip(std::views::iota(0), symbols, prices)
                         | /* enumerate-like patterns tuỳ lib support */) {
    // Tuỳ compiler: dùng views::enumerate nếu có
}
```

Support chi tiết từng view phụ thuộc thư viện chuẩn. Khi thiếu, dùng vòng `for` thường vẫn đúng.

Mẫu mang tính portable: `samples/cpp23/02_print_and_to_underlying.cpp`

## 6. `std::to_underlying` cho `enum class`

```cpp
#include <utility>

enum class OrderSide { Buy = 1, Sell = 2 };
auto raw = std::to_underlying(OrderSide::Buy); // 1
```

Sạch hơn `static_cast<std::underlying_type_t<OrderSide>>(...)`.

## 7. `if consteval`

```cpp
constexpr int f(int x) {
    if consteval {
        return x * x; // chắc chắn đang compile-time
    } else {
        return x + 1; // runtime path
    }
}
```

## 8. `import std;` (khi toolchain sẵn sàng)

```cpp
import std;
int main() {
    std::println("hello");
}
```

Giảm thời gian parse header khổng lồ. Cần compiler + build system hỗ trợ modules tốt.

---

## 9. Có nên nhảy C++23 ngay cho trading-app?

**Thường chưa cần** làm baseline bắt buộc năm học tập:

- Qt ecosystem + Docker image cần compiler đủ mới
- `expected`/`print` rất hấp dẫn nhưng có thể polyfill / tự viết trên C++17
- Ưu tiên ổn định Phase 1–3

Chiến lược:

1. Baseline **C++17** (hoặc **C++20** nếu toolchain sẵn)
2. Theo dõi C++23 feature muốn dùng
3. Nâng chuẩn khi CI/devcontainer hỗ trợ đồng nhất
