# 01 — C++98 / C++03 (Classic C++)

## 1. Bối cảnh

- **C++98**: chuẩn ISO đầu tiên
- **C++03**: chủ yếu sửa defect; lập trình viên thường gọi chung “C++98/03”

Đây là nền mọi thứ sau này xây lên. Bạn không cần viết style 98 cho app mới, nhưng cần nhận ra pattern cũ để migrate.

---

## 2. Đặc điểm nổi bật của kỷ nguyên này

### 2.1. Manual resource management phổ biến

```cpp
// classic style — dễ leak nếu có exception giữa chừng
Order* order = new Order(...);
process(order);
delete order;
```

RAII đã tồn tại (`std::vector`, `std::string`, `std::fstream`) nhưng smart pointer chuẩn còn yếu (`std::auto_ptr` — sau bị loại).

### 2.2. Không có move semantics

Copy nặng. Trả lớn bằng value thường tốn kém (RVO/NRVO giúp một phần, nhưng ngôn ngữ chưa có move).

### 2.3. Không có `auto` kiểu C++11

```cpp
std::map<std::string, std::vector<int> >::iterator it = m.begin();
// lưu ý: >> phải viết > > trong C++98
```

### 2.4. Không có lambda, `nullptr`, `override`, range-for, `enum class`…

Nhiều thứ ngày nay coi là “hiển nhiên” chưa có.

---

## 3. Standard library cốt lõi đã có từ sớm

| Thành phần | Vai trò |
|------------|---------|
| `vector`, `list`, `deque`, `map`, `set` | containers |
| `string` | chuỗi động |
| iterators + `<algorithm>` | generic algorithms |
| `iostream` | I/O |
| exceptions | `try/catch`, `throw` |
| templates | generic programming |

Đây vẫn là nền tảng hiện đại.

---

## 4. Pattern điển hình C++98

### 4.1. Functor thay lambda

```cpp
struct GreaterThan {
    int threshold;
    explicit GreaterThan(int t) : threshold(t) {}
    bool operator()(int x) const { return x > threshold; }
};

std::vector<int> v;
v.erase(std::remove_if(v.begin(), v.end(), GreaterThan(10)), v.end());
```

### 4.2. `std::auto_ptr` (đừng dùng nữa)

```cpp
std::auto_ptr<User> u(new User("alice"));
// transfer ownership bằng copy — semantics nguy hiểm, đã removed ở C++17
```

### 4.3. Trả về container bằng value

```cpp
std::vector<int> makeIds() {
    std::vector<int> ids;
    ids.push_back(1);
    return ids; // dựa vào copy elision / copy
}
```

---

## 5. Điểm kỹ thuật C++03 đáng nhớ

- Value initialization rõ hơn
- Template liên quan `>>` vẫn cần khoảng trắng: `vector<vector<int> >`
- TR1 (Technical Report 1) ngoài chuẩn chính mang `shared_ptr`, `regex`, `unordered_map`… — nhiều thứ vào chuẩn ở **C++11**

---

## 6. Khi nào còn gặp C++98/03?

- Codebase legacy rất cũ
- Embedded toolchains cực hạn chế
- Tài liệu/sách cổ điển

Với trading-app / Qt6: **không chọn C++98/03** làm baseline.

---

## 7. Bài học mang sang modern C++

1. RAII đã đúng từ đầu — hiện đại hóa bằng smart pointer + move
2. STL algorithms vẫn giá trị; lambda chỉ thay functor dài
3. Hiểu copy constructor / assignment là điều kiện để hiểu move sau này (Rule of 3 → Rule of 0/5)

---

## 8. Mini example “classic account”

```cpp
// samples tinh thần C++98
#include <string>
#include <vector>

class Account {
public:
    Account(const std::string& owner, double balance)
        : owner_(owner), balance_(balance) {}

    void deposit(double amount) {
        if (amount > 0) balance_ += amount;
    }

    double balance() const { return balance_; }

private:
    std::string owner_;
    double balance_;
};
```

Sang C++11+: thêm move, `= default`, `enum class` status, `unique_ptr` ownership nếu cần polymorphic service.
