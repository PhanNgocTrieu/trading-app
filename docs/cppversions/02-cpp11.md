# 02 — C++11: Modern C++ bắt đầu

C++11 là bước nhảy lớn nhất kể từ C++98. Nếu chỉ học sâu **một** chuẩn nền, hãy học C++11 kỹ.

Compile mẫu:

```bash
c++ -std=c++11 -Wall -Wextra docs/cppversions/samples/cpp11/*.cpp
```

---

## 1. Tổng quan nhóm feature

| Nhóm | Feature tiêu biểu |
|------|-------------------|
| Type / syntax | `auto`, `decltype`, range-for, trailing return, `nullptr` |
| Classes | `override`/`final`, `=default`/`=delete`, delegating ctor, `enum class` |
| Resource | move semantics, rvalue refs, `unique_ptr`/`shared_ptr`/`weak_ptr` |
| Functional | lambda, `std::function`, `std::bind` |
| Concurrency | `thread`, `mutex`, `lock_guard`, `atomic`, `future`/`async` |
| Library | `array`, `tuple`, `unordered_map`, `chrono`, `regex`, `initializer_list` |
| Compile-time | `constexpr` (hạn chế), `static_assert`, type traits |

## 2. `auto` và range-based for

### Trước (C++98)

```cpp
for (std::vector<Order>::iterator it = orders.begin(); it != orders.end(); ++it) {
    process(*it);
}
```

### C++11

```cpp
for (const auto& order : orders) {
    process(order);
}
```

`auto` suy luận kiểu từ initializer — **không** phải kiểu động như Python.

```cpp
auto x = 42;          // int
auto y = 3.14;        // double
auto& ref = y;        // double&
const auto& s = name; // const string&
```

**Mẹo:** dùng `auto` khi kiểu dài/rõ từ RHS; tránh `auto` khi làm mất ý nghĩa domain (`Money`, `UserId`).

Mẫu: `samples/cpp11/01_auto_range_for.cpp`

## 3. `nullptr` thay `NULL` / `0`

```cpp
void f(int);
void f(char*);

f(0);       // gọi f(int) — bất ngờ
f(NULL);    // phụ thuộc implement
f(nullptr); // gọi f(char*) — đúng ý “con trỏ rỗng”
```

## 4. `enum class` (scoped enum)

```cpp

```

## 5. Move semantics (trái tim C++11)

### Vấn đề

Copy `std::vector` lớn / `std::string` dài tốn kém.

### Ý tưởng

*Move* = “đánh cắp tài nguyên” từ temporary (rvalue), để lại object nguồn ở trạng thái hợp lệ nhưng rỗng.

```cpp
std::vector<int> a = makeBigVector(); // move/elide, không deep copy không cần thiết
std::vector<int> b = std::move(a);    // move tường minh; a hợp lệ nhưng đừng dùng giá trị cũ
```

### Rule of thumb

- Tham số nhận ownership: `void setName(std::string name)` rồi `name_ = std::move(name);`
- Trả lớn bằng value: OK (NRVO/move)
- Member tự quản lý resource: viết move ctor/assign, hoặc dùng member đã move-aware (`string`, `vector`, smart ptr) → **Rule of 0**

Mẫu: `samples/cpp11/02_move_semantics.cpp`

## 6. Smart pointers

| Pointer | Ownership | Dùng khi |
|---------|-----------|----------|
| `unique_ptr` | độc quyền | mặc định |
| `shared_ptr` | chia sẻ ref-count | thật sự shared lifetime |
| `weak_ptr` | không giữ sống | phá chu kỳ `shared_ptr` |

```cpp
#include <memory>

std::unique_ptr<MatchingEngine> engine = std::make_unique<MatchingEngine>(); // C++14 make_unique
// C++11:
std::unique_ptr<MatchingEngine> engine(new MatchingEngine());

std::shared_ptr<IUserRepository> repo = std::make_shared<SqliteUserRepository>(db);
```

**Đừng** dùng `shared_ptr` mọi nơi — chi phí atomic refcount + che giấu ownership.

Mẫu: `samples/cpp11/03_smart_pointers.cpp`

## 7. Lambda

```cpp
std::vector<int> qty = {1, 5, 10, 20};
int threshold = 8;

auto it = std::find_if(qty.begin(), qty.end(),
    [threshold](int q) { return q > threshold; });
```

Capture:

| Capture | Nghĩa |
|---------|--------|
| `[=]` | copy tất cả dùng tới |
| `[&]` | reference tất cả |
| `[x]` / `[&x]` | chỉ định |
| `[=, &db]` | hỗn hợp |

Cẩn thận dangling khi capture reference tới local rồi lưu lambda sống lâu hơn.

Mẫu: `samples/cpp11/04_lambda.cpp`

## 8. Class features quan trọng

```cpp
struct Order {
    Order() = default;
    Order(const Order&) = delete;          // cấm copy
    Order& operator=(const Order&) = delete;
    Order(Order&&) noexcept = default;     // cho phép move
    Order& operator=(Order&&) noexcept = default;

    virtual void apply() {}
};

struct MarketOrder : Order {
    void apply() override; // sai signature → lỗi compile
    // void apply() final;  // cấm override tiếp
};
```

Delegating constructors:

```cpp
User::User(std::string name) : User(std::move(name), "", 0.0) {}
User::User(std::string name, std::string phone, double bal)
    : name_(std::move(name)), phone_(std::move(phone)), bal_(bal) {}
```

## 10. Concurrency cơ bản

```cpp
#include <thread>
#include <mutex>
#include <atomic>

std::mutex mu;
std::atomic<bool> running{true};

void worker() {
    while (running.load()) {
        std::lock_guard<std::mutex> lock(mu);
        // critical section
    }
}

std::thread t(worker);
// ...
running = false;
t.join();
```

Với Qt sau này: ưu tiên Qt threading model cho UI; `std::thread` vẫn hữu ích ở domain/engine tests.

Mẫu: `samples/cpp11/05_thread_mutex.cpp`

## 12. `constexpr` và `static_assert` (mức C++11)

```cpp
constexpr int square(int x) { return x * x; } // thân hàm rất hạn chế ở C++11
static_assert(sizeof(void*) >= 4, "need 32-bit+");
```

`constexpr` sẽ mạnh dần ở 14/17/20.

## 13. Áp dụng vào trading-app (từ code hiện tại)

Repo đang ở tinh thần C++11:

- Singleton services
- `typedef enum` kiểu C → nên thành `enum class`
- Raw `std::string` + cout UI
- Chưa thấy move/`unique_ptr` rõ ràng

Checklist “C++11-ify”:

1. `enum class` cho status
2. `nullptr`
3. range-for
4. `override` trên destructor/virtual (nếu có hierarchy)
5. `unique_ptr` cho engine/repos thay raw ownership
6. lambda cho callbacks nhỏ

## 14. Những thứ C++11 **chưa** có (để chờ chuẩn sau)

- `std::make_unique` → C++14
- `std::optional`, `std::string_view`, `std::filesystem` → C++17
- Concepts / Ranges / Coroutines → C++20
- `std::expected` → C++23

## 15. Tóm tắt tinh thần C++11

> Sở hữu rõ ràng, di chuyển thay vì copy, biểu đạt ngắn bằng `auto`/lambda, an toàn hơn bằng `enum class`/`override`/`nullptr`, và concurrency vào chuẩn.
