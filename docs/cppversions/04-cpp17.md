# 04 — C++17: Baseline thực dụng cho ứng dụng hiện đại

C++17 là chuẩn **đáng chọn làm mặc định** cho trading-app (Qt + SQL + domain). Nhiều feature giải quyết đúng pain point app thực tế.

```bash
c++ -std=c++17 -Wall -Wextra docs/cppversions/samples/cpp17/*.cpp
```

---

## 1. Headline features

### Core language

- Structured bindings
- `if` / `switch` với init-statement
- `if constexpr`
- Fold expressions
- Inline variables
- Guaranteed copy elision (prvalues)
- `[[nodiscard]]`, `[[maybe_unused]]`, `[[fallthrough]]`
- Nested namespace definition: `namespace A::B { }`
- `*` selection cho template template (CTAD bắt đầu mạnh)

### Library

- `std::optional`, `std::variant`, `std::any`
- `std::string_view`
- `std::filesystem`
- `std::shared_mutex`
- Parallel algorithms (`std::execution`)
- `std::byte`
- `std::clamp`, `std::gcd`/`lcm`
- `std::apply`, `std::invoke`
- Conjunction/disjunction type traits helpers

## 2. `std::optional` — “có hoặc không”

Thay sentinel/`nullptr`/bool+value tách rời.

```cpp
#include <optional>
#include <string>

std::optional<User> findUser(const std::string& name);

if (auto user = findUser("alice")) {
    std::cout << user->username() << "\n";
} else {
    std::cout << "not found\n";
}
```

Repository pattern:

```cpp
class IUserRepository {
public:
    virtual std::optional<User> findByUsername(const std::string&) = 0;
};
```

Mẫu: `samples/cpp17/01_optional.cpp`

## 3. `std::variant` / `std::any`

### `variant` — union có kiểu an toàn

```cpp
#include <variant>

using PriceOrError = std::variant<double, std::string>;

PriceOrError quote(const std::string& symbol) {
    if (symbol.empty()) return std::string{"empty symbol"};
    return 190.5;
}

auto q = quote("AAPL");
if (std::holds_alternative<double>(q)) {
    use(std::get<double>(q));
}
```

Hoặc `std::visit`.

### `any` — type erasure linh hoạt (dùng thận trọng)

Thường kém rõ ràng hơn `variant`/`optional`. Ưu tiên kiểu cụ thể.

## 4. `std::string_view` — nhìn chuỗi không sở hữu

```cpp
#include <string_view>

bool isBuy(std::string_view side) {
    return side == "BUY" || side == "buy";
}

// nhận cả string literal và std::string mà không copy
isBuy("BUY");
std::string s = "SELL";
isBuy(s);
```

**Cẩn thận dangling:**

```cpp
std::string_view bad() {
    std::string tmp = "AAPL";
    return tmp; // DANGER: view vào object sắp chết
}
```

Dùng `string_view` cho tham số đọc; dùng `string` khi cần sở hữu/lưu trữ.

Mẫu: `samples/cpp17/02_string_view.cpp`

## 7. `if constexpr` — nhánh compile-time trong template

```cpp
template <typename T>
auto valueOrDefault(const std::optional<T>& o) {
    if constexpr (std::is_arithmetic_v<T>) {
        return o.value_or(T{0});
    } else {
        return o.value_or(T{});
    }
}
```

Khác `if` thường: nhánh false được **loại ở compile-time** (với điều kiện constant).

## 8. `std::filesystem`

```cpp
#include <filesystem>
namespace fs = std::filesystem;

fs::path dbPath = fs::path{std::getenv("HOME")} / ".trading-app" / "trading.db";
fs::create_directories(dbPath.parent_path());
if (fs::exists(dbPath)) {
    auto bytes = fs::file_size(dbPath);
}
```

Tuyệt vời cho đường dẫn DB, log dir, migration files.

Mẫu: `samples/cpp17/04_filesystem.cpp`

## 9. Attributes quan trọng

```cpp
[[nodiscard]] Result<Order> placeOrder(const PlaceOrderCommand&);

auto r = placeOrder(cmd);          // warning nếu bỏ kết quả
(void)placeOrder(cmd);             // cố ý bỏ — vẫn nên dùng

[[maybe_unused]] int debugOnly = 1;

switch (status) {
    case OrderStatus::Pending:
        handlePending();
        [[fallthrough]];
    case OrderStatus::Filled:
        handleFilled();
        break;
}
```

`[[nodiscard]]` đặc biệt hợp API trading (không được im lặng bỏ qua lỗi đặt lệnh).

## 11. Fold expressions (variadic templates gọn)

```cpp
template <typename... Args>
auto sum(Args... args) {
    return (args + ...); // unary right fold
}
```

Ít dùng trực tiếp trong app UI, hay gặp trong library/generic code.

---

## 12. CTAD — Class Template Argument Deduction

```cpp
std::pair p{1, 2.0};          // pair<int,double>
std::lock_guard lock(mu);     // lock_guard<mutex>
std::vector v{1, 2, 3};       // vector<int>
```

---

## 13. Parallel algorithms (biết để dùng đúng chỗ)

```cpp
#include <execution>
#include <algorithm>

std::sort(std::execution::par, prices.begin(), prices.end());
```

Không phải lúc nào cũng nhanh hơn; overhead + không dùng chung với cấu trúc không thread-safe. Với paper trading v1: thường **không cần**.

## 14. Áp dụng trực tiếp cho trading-app

| Nhu cầu dự án | Feature C++17 |
|---------------|----------------|
| `findUser` có/không | `optional` |

## 16. Tóm tắt tinh thần C++17

> Biểu đạt ý định “có/không”, “một trong vài kiểu”, “nhìn chuỗi không copy”, thao tác file path chuẩn, và siết API bằng attributes — đủ để viết app production-style hiện đại.
