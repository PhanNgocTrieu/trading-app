# 03 — C++14: Hoàn thiện C++11

C++14 không “đổi đời” như C++11, nhưng vá nhiều chỗ khó chịu. Nếu đã dùng C++11, gần như luôn nên bật ít nhất C++14.

```bash
c++ -std=c++14 -Wall -Wextra docs/cppversions/samples/cpp14/*.cpp
```

---

## 1. Headline features

| Feature | Vì sao hữu ích |
|---------|----------------|
| `std::make_unique` | đối xứng `make_shared`, exception-safe |
| Generic lambdas (`auto` params) | generic callbacks ngắn |
| Return type deduction cho hàm thường | bớt trailing return |
| Relaxed `constexpr` | hàm compile-time mạnh hơn |
| Binary literals / digit separators | `0b1010`, `1'000'000` |
| `std::shared_timed_mutex`, `std::integer_sequence`… | niche nhưng hữu ích |

---

## 2. `std::make_unique`

### C++11

```cpp
std::unique_ptr<User> u(new User("alice"));
// hoặc hack tự viết make_unique
```

### C++14

```cpp
#include <memory>
auto u = std::make_unique<User>("alice");
auto arr = std::make_unique<int[]>(10);
```

Lý do an toàn:

```cpp
// nguy hiểm kiểu cũ nếu có nhiều new trong cùng expression và có exception
foo(std::unique_ptr<A>(new A), std::unique_ptr<B>(new B));
// make_unique giúp giảm rủi ro leak trong expression phức tạp
foo(std::make_unique<A>(), std::make_unique<B>());
```

Mẫu: `samples/cpp14/01_make_unique.cpp`

## 3. Generic lambda

```cpp
auto add = [](auto a, auto b) { return a + b; };
add(1, 2);       // int
add(1.5, 2.5);   // double
add(std::string("a"), std::string("b"));
```

Áp dụng:

```cpp
std::vector<std::string> symbols{"AAPL", "MSFT"};
std::vector<int> qty{10, 5};

auto printAll = [](const auto& xs) {
    for (const auto& x : xs) std::cout << x << ' ';
    std::cout << '\n';
};
printAll(symbols);
printAll(qty);
```

## 4. Function return type deduction

```cpp
auto makeLoginStatus(bool ok) {
    return ok ? LoginStatus::Success : LoginStatus::Failure;
}
```

Vẫn nên tránh khi return type là một phần API public quan trọng — ghi tường minh giúp đọc header.

---

## 5. Relaxed `constexpr`

C++11: `constexpr` function gần như chỉ được 1 `return` expression.

C++14: cho phép local variables, vòng lặp, nhánh:

```cpp
constexpr int factorial(int n) {
    int r = 1;
    for (int i = 2; i <= n; ++i) r *= i;
    return r;
}
static_assert(factorial(5) == 120, "");
```

## 6. Digit separators & binary literals

```cpp
int cash_cents = 1'000'000; // dễ đọc
int flags = 0b0001'0100;
double price = 1'234.567'8; // OK với separator
```

Hữu ích khi sau này migrate sang integer cents trong trading-app.

---

## 7. `[[deprecated]]` attribute (thực dụng)

```cpp
[[deprecated("use Account::cash() instead")]]
double User::balance() const;
```

Compiler sẽ cảnh báo chỗ gọi cũ — tốt cho migrate dần.

---

## 8. Nên dùng C++14 khi nào?

- Toolchain hỗ trợ C++11 nhưng chưa chắc C++17 (hiếm năm 2026)
- Muốn `make_unique` + generic lambda ngay

Với trading-app hiện tại: **đừng dừng ở 14** — nhảy thẳng **17** nếu compiler cho phép (Ubuntu 24.04 / Apple Clang hiện đại đều ổn).

## 9. Tóm tắt

> C++14 = C++11 dễ thở hơn. Feature “phải nhớ”: `make_unique`, generic lambda, `constexpr` rộng, digit separators.
